# ☕ Bootcamp Itaú | Java com Inteligência Artificial

Repositório dedicado aos desafios de código e projetos desenvolvidos durante o **Bootcamp Itaú – Java com Inteligência Artificial**, oferecido pela [DIO](https://www.dio.me/).

O objetivo deste repositório é documentar minha jornada de aprendizado, reunindo as soluções desenvolvidas para os desafios propostos ao longo da formação e colocando em prática os conhecimentos adquiridos.

## 🎯 Sobre o Bootcamp

O Bootcamp Itaú – Java com Inteligência Artificial tem como objetivo aprofundar conhecimentos em desenvolvimento Java e explorar as possibilidades de integração entre programação e Inteligência Artificial.

Durante a formação, são trabalhados conceitos e tecnologias relacionados a:

- Fundamentos de Java e lógica de programação.
- Programação Orientada a Objetos (POO).
- Boas práticas de desenvolvimento e padrões de projeto.
- Desenvolvimento de APIs REST com Spring Boot.
- Persistência de dados e segurança com Spring.
- Fundamentos e aplicações de Inteligência Artificial.
- Utilização de IA generativa no desenvolvimento de software.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java
- **Framework:** Spring Boot
- **Persistência:** Spring Data
- **Segurança:** Spring Security
- **Versionamento:** Git e GitHub
- **Inteligência Artificial:** IA Generativa e LLMs

## 🚀 Objetivos de Aprendizado

- Consolidar os fundamentos da linguagem Java.
- Aprimorar o raciocínio lógico por meio de desafios práticos.
- Aplicar conceitos de orientação a objetos.
- Desenvolver soluções utilizando o ecossistema Spring.
- Explorar aplicações de Inteligência Artificial no desenvolvimento de software.
- Aprimorar a capacidade de resolução de problemas e organização de código.

## 📈 Evolução

Este repositório será atualizado conforme o avanço no bootcamp, reunindo os desafios resolvidos e projetos desenvolvidos durante a formação.

Mais do que armazenar códigos, a proposta é registrar minha evolução como desenvolvedor Java, consolidando conhecimentos por meio da prática.
